# 2026 数学建模 C 题

本仓库保存 C 题目前阶段的建模代码、数据处理结果、求解结果、报告和论文图表。

## 目录说明

- `code/`：数据预处理、LP/MILP 求解、结果对比及工作簿生成代码
- `figures/`：论文可用图表
- `reports/`：建模分析报告、结果报告和运行说明
- `predata/`：优化模型标准输入数据
- `附件/`：题目附件及结果模板
- `C题.pdf`：题目文件
