# 问题四运行说明

## 主程序

```powershell
python code\14_问题四_周期电价与联合场景MILP.py --policies all
```

主程序读取附件 1—4，完成以下工作：

1. 计算整日滞后 ACF，建立与第二、三问一致的 \(\rho=0.8\) 四周固定指数电价预测，并在 6:00、12:00、18:00 进行门控残差岭回归更新；
2. 生成价格—负荷—光伏同历史日联合残差场景；
3. 求解问题 4-2 与问题 4-3 的全年滚动 MILP；
4. 按附件 4 真实价格独立结算；
5. 比较四种日内更新策略并计算价格完全信息下界；
6. 输出中间 CSV、JSON 与五张论文用 PDF 图。

完整运行耗时主要来自全年 MILP。可用以下续算入口单独重跑某个阶段：

```powershell
# 只补算价格完全信息下界
python code\14_问题四_周期电价与联合场景MILP.py --oracle-only

# 只补算0点、6点、6/12点三组对照策略
python code\14_问题四_周期电价与联合场景MILP.py --policy-comparison-only

# 只重绘论文图
python code\14_问题四_周期电价与联合场景MILP.py --plots-only

# 用较短区间调试正式策略，不算下界、不画图
python code\14_问题四_周期电价与联合场景MILP.py --policies official --skip-oracle --skip-plots --end-date 2025-02-07
```

## 生成提交工作簿

主程序完成后运行：

```powershell
node code\15_问题四_生成结果工作簿.mjs
```

输出目录为 `code/outputs/问题四/`：

- `result4-2.xlsx`
- `result4-3.xlsx`
- `问题四_全年结果与校验.xlsx`

工作簿生成器直接导入附件 5 的官方模板，保留原有表结构，写入 2025-02-01 至 2025-12-31 共 334 天的结果，并自动进行公式错误扫描与 PNG 预览渲染。

## 核心公共模块

- `problem4_price_common.py`：固定指数周期预测、ACF、岭回归日内更新、因果门控、价格场景和预测指标。
- `problem2_solver_common.py`：问题 4-2 使用的多价格场景日 MILP。
- `problem3_solver_common.py`：问题 4-3 使用的多价格场景滚动时域 MILP。

`problem2_solver_common.py` 与 `problem3_solver_common.py` 同时兼容原问题2/3的一维确定价格输入；已有模型自检脚本已回归通过。
