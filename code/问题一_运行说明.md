# 问题一两种求解思路运行说明

## 文件分工

- `problem1_solver_common.py`：统一读取数据、构建约束、校验结果和输出中间数据。
- `01_问题一_LP连续线性规划.py`：只运行连续 LP，并在求解后核查同时充放电。
- `02_问题一_MILP充放电互斥.py`：只运行带二进制互斥变量的 MILP。
- `03_问题一_LP与MILP结果对比.py`：同时运行无储能、LP 和 MILP 三种方案，生成对比数据和 PDF 图。
- `04_问题一_生成结果工作簿.mjs`：把中间数据写入规范结果工作簿和附件 5 的 result1 提交模板。

## 运行环境

需要 Python 3、NumPy、pandas、SciPy、Matplotlib，以及 Node.js。LP 与 MILP 均调用 SciPy 所带的 HiGHS 求解器。

## 完整复现

在项目根目录执行：

```powershell
python code\03_问题一_LP与MILP结果对比.py
node code\04_问题一_生成结果工作簿.mjs
```

若只想单独核查某种模型：

```powershell
python code\01_问题一_LP连续线性规划.py
python code\02_问题一_MILP充放电互斥.py
```

Python 脚本把复核所需的 JSON、CSV 等中间数据写到 `tmp/问题一_求解中间结果/`；运行工作簿脚本后，`code/outputs/问题一/` 只保留三份提交格式工作簿和一份三方案对比工作簿。

## 统一模型口径

- 每时段 10 分钟，功率乘以 `1/6 h` 转为电量。
- 充电效率与放电效率均为 90%。
- 储电量范围为 1200 至 10800 kWh，日初和日末均为 6000 kWh。
- 充电与放电功率上限均为 5000 kW，即单时段电量上限为 833.333333 kWh。
- 允许弃光，弃光不收费；两种模型均以全天购电费用最小为唯一目标。
- 附件 1 的 144 行与 result1 的 144 行按顺序映射，同时在详细结果中保留原始时刻、模型时段和模板时段。
