# 问题三运行说明

## 文件分工

- `problem3_solver_common.py`：附件 3 读取、线性插值、联合残差场景和通用剩余时域 MILP。
- `10_问题三_模型自检.py`：时间映射、插值、净结算和小规模 MILP 自检。
- `11_问题三_四时点滚动MILP.py`：四策略全年回测、实际结算、中间数据和论文图。
- `12_问题三_生成结果工作簿.mjs`：使用附件 5 模板生成提交工作簿和审计工作簿。
- `13_问题三_重绘论文图.py`：从已有 CSV 重绘论文图，不重复全年求解。

## 完整运行

```powershell
python code\10_问题三_模型自检.py
python code\11_问题三_四时点滚动MILP.py
node code\12_问题三_生成结果工作簿.mjs
```

只重绘图表：

```powershell
python code\13_问题三_重绘论文图.py
```

单策略或短区间调试：

```powershell
python code\11_问题三_四时点滚动MILP.py --policy S61218_全部四时点 --end-date 2025-02-05 --skip-plots
```
