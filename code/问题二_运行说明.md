# 问题二运行说明

## 文件分工

- `problem2_solver_common.py`：数据读取、周期预测、联合残差场景、日备不足惩罚 MILP 和校验。
- `05_问题二_周期预测与风险MILP.py`：全年求解、实际结算、汇总和论文图。
- `06_问题二_模型自检.py`：预测公式、信息边界和小规模 MILP 自检。
- `07_问题二_生成结果工作簿.mjs`：填充附件 5 模板并生成审计工作簿。
- `08_问题二_重绘论文图.py`：读取已有结果重新生成论文图，不重复求解。
- `09_问题二_日备惩罚对比校验.py`：独立复算有、无日备不足惩罚的费用和储能差异。

## 完整运行

在项目根目录执行：

```powershell
python code\06_问题二_模型自检.py
python code\05_问题二_周期预测与风险MILP.py --variant no-reserve
python code\05_问题二_周期预测与风险MILP.py --variant reserve
python code\09_问题二_日备惩罚对比校验.py
node code\07_问题二_生成结果工作簿.mjs
```

## 只重绘论文图

```powershell
python code\08_问题二_重绘论文图.py
```

若只重绘受日备惩罚影响的全年调度图和方案对比图：

```powershell
python code\08_问题二_重绘论文图.py --optimization-only
```

若只重绘严格按 2025 年公历分组的星期曲线、日备惩罚对比图，以及含 3 月 20 日储电量的 24 小时预测图：

```powershell
python code\08_问题二_重绘论文图.py --weekday-comparison-only
```

若只重绘包含合并预测功率图与合并实际过程图的 3 月 20 日紧凑图：

```powershell
python code\08_问题二_重绘论文图.py --intraday-only
```

## 运行要求

- Python 需要 NumPy、pandas、SciPy、Matplotlib、statsmodels 和 openpyxl。
- Node.js 需要 Codex primary runtime 中的 `@oai/artifact-tool`。
- 主程序使用按日期固定的场景随机种子，结果可复现。
- 正式结果区间为 2025 年 2 月 1 日至 12 月 31 日。
- 当前环境中每套全年方案约需 10 分钟；完整对比需要依次运行两套方案。
