# 计算结果

## 运行环境

问题一使用 Python 3.14、SciPy 1.16.3 与 HiGHS 求解器完成。结果工作簿使用项目既有的表格工具生成并完成结构、公式错误和渲染检查。

## 数据读取与预处理

模型读取 `predata/问题一_优化模型标准输入.xlsx` 的 144 个 10 分钟时段。小区负荷和光伏预测功率由 kW 乘以 `1/6 h` 转换为 kWh。电价单位保持为元/kWh。

两种方法使用完全相同的参数：储电量下限 1200 kWh、上限 10800 kWh、日初及日末储电量 6000 kWh；充电与放电功率上限均为 5000 kW；充、放电效率分别为 90%。模型允许弃光。

附件 1 与 result1 模板存在 10 分钟标签口径歧义。本次继续采用建模报告确定的基准口径：模型内部把附件 1 的时刻看作区间终点，写入 result1 时按 144 行顺序一一对应。逐时段结果同时保存原始时刻、模型时间段和提交模板时间段，便于后续统一调整。

## 问题一结果

### 对照组：不使用储能

无储能基准不设置充电量、放电量和储电状态变量。每个时段优先使用光伏满足负荷，净负荷为正时全部从外部电网购买，光伏超过负荷时将超出部分记为弃光：

```text
G_t = max(L_t-P_t, 0)
W_t = max(P_t-L_t, 0)
```

无储能方案的全天购电费用为 **48052.046591 元**，购电量为 **61789.935400 kWh**，弃光量为 **6247.962967 kWh**。最大逐时段电力平衡残差为 `1.14×10^-13 kWh`。

### 思路一：连续线性规划并事后核查

LP 模型不引入充放电状态变量。目标函数为全天购电费用，约束包括逐时段电力平衡、储电状态递推、储电量边界、充放电功率边界、弃光边界和日末储电量回归。

LP 获得全局最优解，最小购电费用为 **35126.948589 元**。全天购电量为 **59482.698998 kWh**，充电量为 **20740.666132 kWh**，放电量为 **16799.939567 kWh**，弃光量为 **0 kWh**。

求解后逐时段检查 `充电量 > 10^-6` 且 `放电量 > 10^-6` 的情况，结果为 **0 个时段**。因此，本数据下“不显式添加互斥变量”的 LP 方案满足充放电互斥要求，不需要触发修正。

### 思路二：显式充放电互斥的混合整数线性规划

MILP 在 LP 全部变量和约束的基础上，为每个时段增加二进制变量 `z_t`，并设置：

```text
C_t <= 833.333333 z_t
D_t <= 833.333333 (1-z_t)
```

MILP 同样获得全局最优解，整数相对间隙为 **0**。最小购电费用为 **35126.948589 元**。全天购电量为 **59482.698998 kWh**，充电量为 **20740.666132 kWh**，放电量为 **16799.939567 kWh**，弃光量为 **0 kWh**。显式互斥约束核查通过，同时充放电时段数为 **0**。

### 三种方案比较

| 指标 | 无储能基准 | LP（事后核查） | MILP（显式互斥） |
| --- | ---: | ---: | ---: |
| 购电费用/元 | 48052.046591 | 35126.948589 | 35126.948589 |
| 较无储能节省费用/元 | 0 | 12925.098002 | 12925.098002 |
| 较无储能节省率 | 0 | 26.8981% | 26.8981% |
| 全天购电量/kWh | 61789.935400 | 59482.698998 | 59482.698998 |
| 全天充电量/kWh | 0 | 20740.666132 | 20740.666132 |
| 全天放电量/kWh | 0 | 16799.939567 | 16799.939567 |
| 弃光量/kWh | 6247.962967 | 0 | 0 |
| 同时充放电时段数 | 0 | 0 | 0 |
| 最大电力平衡残差/kWh | 1.14×10^-13 | 1.14×10^-13 | 1.14×10^-13 |

与无储能方案相比，储能使购电费用减少 **12925.098002 元**，降幅为 **26.8981%**；同时把弃光量从 **6247.962967 kWh** 降为 0。储能方案的购电量比无储能方案少 **2307.236402 kWh**。虽然储能充放电存在能量损耗，但对富余光伏的吸收和峰谷电价套利共同降低了外购电量与购电费用。

两种方法的最优费用和全天汇总量一致，说明 LP 松弛在本数据上已经给出满足互斥条件的最优方案。MILP 提供了结构上的互斥保证，但求解规模更大。

两套逐时段轨迹不完全逐点相同。购电计划有 2 个时段不同，最大逐时段购电量差为 333.333333 kWh，最大储电量差为 300 kWh。差异发生在 23:10-23:20 与 23:30-23:40：两时段电价相同，充电量可以在其间移动而不改变费用、总量或最终储电量。这是多重最优解导致的等价调度，不是模型不一致。

## 约束与一致性校验

两种结果均通过以下检查：

- 最大逐时段电力平衡残差为 `1.14×10^-13 kWh`。
- 最大储电状态递推残差为 `8.81×10^-13 kWh`。
- 储电量始终位于 1200 至 10800 kWh 范围内。
- 日末储电量准确回到 6000 kWh。
- 最大单时段充电量为 833.333333 kWh，未超过功率上限。
- 最大单时段放电量为 715.653033 kWh，未超过功率上限。
- 求解器目标值与独立复算费用之差约为 `7.28×10^-12 元`。
- LP 和 MILP 的同时充放电时段数均为 0。
